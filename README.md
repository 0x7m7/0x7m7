# 0x7m7

**Systems-focused software engineer. C++ at the core.**

I work close to the machine: performance, memory, concurrency, and the infrastructure that other software depends on. My approach is to understand a system from the hardware up, then build on that understanding.

---

## Focus Areas

**Systems and Performance Engineering**
Memory layout, cache behavior, allocation strategies, profiling, and benchmarking. I care about why code is fast or slow, not just whether it runs.

**Concurrency and Parallelism**
Threads, synchronization, atomics, and the C++ memory model. Designing for correctness first, then throughput.

**Compilers and Toolchains**
How source becomes machine code: parsing, optimization passes, and the generated assembly. Reading compiler output is part of my workflow.

**Databases and Storage**
Storage engines, indexing structures, and the tradeoffs behind query performance.

**GPU and High-Performance Computing**
Parallel computation and the infrastructure behind modern AI workloads.

**Operating Systems and Networking**
Linux internals, processes, sockets, and distributed systems fundamentals.

---

## How I Work

- **Fundamentals first.** I would rather understand one layer deeply than skim five.
- **Measure, don't guess.** Profile before optimizing. Benchmark before claiming.
- **Correctness tooling by default.** Strict warnings, sanitizers (ASan, UBSan), and tests from the start.
- **Modern C++.** C++17/20 idioms, RAII, and clear ownership over manual resource management.
- **Read real code.** Studying production codebases is as important as writing my own.
- **Communicate clearly.** Concise commits, precise documentation, and thoughtful code review.
